# pour personnaliser sa page tout est dans l'index 

- Pour changer la photo de profil, placez votre photo dans le dossier « assets » et nommez-la « avatar » (avec l'extension .jpg) ; faites de même pour la vignette de la musique et le fichier audio (« song.mp3 »).
- To change the profile picture, place your photo in the "assets" folder and name it "avatar" (with the .jpg extension); do the same for the music thumbnail and the audio file ("song.mp3").
